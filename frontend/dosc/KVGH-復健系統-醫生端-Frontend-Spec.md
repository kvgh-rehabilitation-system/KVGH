# KVGH 復健系統－醫生端 Frontend Spec

## 1. 問題分析

醫生端目前收斂為三個主導覽頁：

1.  首頁
2.  病患列表
3.  復健計畫

「看診記錄」不作為主導覽頁。

看診記錄必須依附於特定病患，因此操作入口放在「病患詳細資料」內，避免醫生進入空白看診表單後再次搜尋病患。

------------------------------------------------------------------------

## 2. 資訊架構

``` text
醫生端
│
├── 首頁
│   └── 今日病患 / 待處理資訊
│
├── 病患列表
│   └── 病患詳細資料
│       ├── 基本資料
│       ├── 看診歷史
│       ├── 新增本次看診記錄
│       └── 病患復健計畫
│
└── 復健計畫
    └── 復健計畫詳細資料
        ├── 當前有效計畫
        ├── 執行狀況
        └── 歷史計畫 / 歷史版本
```

# 13. 結論

醫生端第一版主導覽固定為：

``` text
首頁
病患列表
復健計畫
```

工作流程：

``` text
首頁
 ↓
查看今日工作

病患列表
 ↓
找到病患
 ↓
病患詳細資料
 ↓
查看歷史
 ↓
新增本次看診記錄
 ↓
建立 / 持續 / 調整 / 結束復健計畫

復健計畫
 ↓
查看所有有效計畫
 ↓
找到需要評估的計畫
 ↓
查看計畫詳細
 ↓
調整或結束計畫
```

核心設計原則：

> 看診記錄屬於病患，因此不放主導覽。

> 病患列表負責「找人」。

> 復健計畫負責「管理目前正在追蹤的復健計畫」。

> 首頁負責「今天醫生需要做什麼」。
